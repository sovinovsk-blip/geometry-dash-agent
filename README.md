# Geometry Dash Agent (Android, experimental source)

**Это исходный проект, НЕ готовый APK и НЕ гарантированный бот-профессионал.**

## Как собрать
- Нужны Android Studio с Android SDK 35 и JDK 17, либо совместимый Gradle/Android SDK.
- Откройте эту папку как Android-проект, дождитесь синхронизации Gradle.
- Build > Build APK(s). Полученный APK обычно лежит в `app/build/outputs/apk/debug/`.
- Установите APK на Android 11+ и откройте приложение.
- Вставьте Perplexity API key, сохраните, включите службу доступности в настройках Android.
- Откройте Geometry Dash и уровень; вернитесь в приложение и нажмите «Включить бота», затем переключитесь в игру.
- Остановка: вернитесь в приложение и нажмите «Остановить» либо выключите службу доступности.

## Важные ограничения
- Приложение экспериментальное. Perplexity API может не поддерживать входные изображения с выбранной моделью, и тогда запросы завершатся ошибкой.
- Сетевой анализ кадров слишком медленный для точного прохождения Geometry Dash. Нет распознавания препятствий на высокой частоте, предсказания траекторий, памяти попыток и обучения. Для профессиональной игры необходим локальный быстрый алгоритм управления.
- Сервис распознаёт стандартный пакет `com.robtopx.geometryjump`. Для других редакций игры понадобится другая настройка.
- Бот работает только когда включён и на переднем плане Geometry Dash. Android может ограничивать фоновые службы.
- Ключ хранится в локальных настройках приложения без дополнительного шифрования. Не распространяйте APK со встроенным ключом.
- Доступность и скриншоты — чувствительные разрешения. Используйте приложение только на своём устройстве и по назначению.
- Для сборки APK из исходников требуется Android SDK/Gradle. Если ничего устанавливать нельзя, соберите проект на компьютере, где уже установлена среда, или в доверенной облачной Android-сборке.

## Что улучшено в версии 2
- Поддержка обнаружения стандартных пакетов Geometry Dash и Geometry Dash Lite.
- Кадры сжимаются до 720 пикселей по ширине, чтобы уменьшить размер сетевых запросов.
- Промпт не предлагает прыгать на экранах меню, смерти и загрузки.
- Приложение не работает как полноценный высокочастотный игровой контроллер: на каждом запросе всё ещё есть сетевая задержка.

## Без установки программ из интернета
На самом телефоне после сборки нужен только APK. Если нет компьютера с Android SDK и Gradle, из одного ZIP исходников APK автоматически не появится.
